# Sandra Subash — Python Developer Portfolio

A responsive, single-page portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser, or use the **Live Server** extension in VS Code.
3. Edit `index.html` to update the contact email and profile links before publishing.

## Customize before publishing
- Replace `your.email@example.com` with your real professional email.
- Update the GitHub and LinkedIn URLs with your profiles.
- Replace each project's placeholder GitHub URL with its actual repository URL (Smart Task Management System, Product Catalog, and DailyMart).
- Add a downloadable resume link if you want one.
- Review project descriptions to ensure they match the exact features in your code.

## Deploy
You can publish this static site with GitHub Pages, Netlify, or Vercel. No build step is required.
